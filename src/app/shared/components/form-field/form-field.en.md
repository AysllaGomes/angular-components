# Text field (`app-form-field`)

> Default texts in **English**, changeable in one place with [`provideUiLabels`](../../labels/labels.en.md) (`labels.*` in the tables below); each instance's input wins.

A frame for **native** `<input>`, `<textarea>` and `<select>`: label, "required", hint, error, character counter, prefix/suffix and a show-password button. The field is still the native element, so `formControl`, `ngModel`, `appMask`, `type`, `autocomplete` and `inputmode` work as usual. To make a `<textarea>` grow with its text, use the `appAutosize` directive.

- **Files:** `src/app/shared/components/form-field/form-field.component.ts` and `autosize.directive.ts`

| When to use | Component |
|---|---|
| Free text, number, email, password, tax id (with `appMask`) | **`app-form-field`** + `<input>` |
| Long text (notes, description) | **`app-form-field`** + `<textarea appAutosize>` |
| Picking among known options | `app-select` |
| Options in a tree | `app-tree-select` |

## Why it exists

An accessible text field needs a label tied by `for`/`id`, hint and error tied by `aria-describedby`, `aria-invalid` and `aria-required` in the right place, and the same look across the form. Components that **recreate** the `<input>` tend to hide native attributes (`type`, `autocomplete`, `inputmode`) and get in the way of masks and password managers. This frame does the opposite: you write the native `<input>` and it wires everything onto it, and adds a counter, prefix/suffix and show-password without reinventing the field.

## When to use

### Use when

- People type: name, email, phone, tax id (with `appMask`), amounts, password, notes.
- The field has a character limit worth showing (`maxlength` + `counter`).
- A unit or symbol sits next to the value, such as "$" or "kg".

### Prefer another

- The possible answers are known: use the [Select](../select/select.en.md), or the [Radio group](../radio/radio-group.en.md) if they are few and fit on screen.
- Options organized in levels: use the [TreeSelect](../tree-select/tree-select.en.md).
- A yes/no: use the [Checkbox](../checkbox/checkbox.en.md) or, if it applies right away, the [Switch](../switch/switch.en.md).

## Usage

```html
<app-form-field label="Email" required hint="We use it to recover your password" [error]="form.controls.email | fieldError">
  <input type="email" autocomplete="email" formControlName="email">
</app-form-field>

<app-form-field label="Password" required passwordToggle>
  <input type="password" autocomplete="current-password" formControlName="password">
</app-form-field>

<app-form-field label="Order amount">
  <span ffPrefix>$</span>
  <input inputmode="decimal" formControlName="amount">
</app-form-field>

<app-form-field label="Notes" counter hint="Only the team sees this">
  <textarea maxlength="280" appAutosize="6" formControlName="notes"></textarea>
</app-form-field>
```

- **Counter** (`counter`): shows "42/280" from the field's `maxlength` and follows typing and values set by the form (`setValue`, `reset`). Screen readers hear "42 of 280 characters" on focus and, near the limit, "5 characters left" after a pause in typing (not on every key).
- **Prefix and suffix** (`[ffPrefix]` / `[ffSuffix]`): sit inside the box and are **not** part of the value. With text ("$", "kg") they describe the field for screen readers; an icon with no text does not (mark it `aria-hidden="true"`).
- **Show password** (`passwordToggle`): a button inside the field that switches between `password` and `text`. The password is hidden again when the form is submitted.
- **Growing textarea** (`appAutosize`): the height follows the text up to the max rows, then it scrolls. It also follows values set by the form and the field width.

## API

### `app-form-field` · Inputs

| Prop                 | Type             | Default                  | Description |
|----------------------|------------------|--------------------------|-------------|
| `label`              | `string`         | `''`                     | Field label (tied by `for`/`id`). |
| `required`           | `boolean`        | `false`                  | Shows the marker and sets `aria-required` on the field. To validate, use the form validator. |
| `requiredLabel`      | `string`         | `labels.required`        | Marker text. |
| `hint`               | `string \| null` | `null`                   | Hint below the field (hidden while there is an error). |
| `error`              | `string \| null` | `null`                   | Error (e.g. `ctrl \| fieldError`); sets `aria-invalid`. |
| `counter`            | `boolean`        | `false`                  | Shows "n/max" from the field's `maxlength`. |
| `counterAnnounceAt`  | `number \| null` | 20% of the limit (min. 5) | From how many characters left screen readers hear "N characters left". |
| `passwordToggle`     | `boolean`        | `false`                  | Show/hide button on `<input type="password">`. |
| `showPasswordLabel`  | `string`         | `labels.formField.showPassword` | Button name (the state goes in `aria-pressed`). |

Slots: `[ffPrefix]` and `[ffSuffix]` (content inside the box, before and after the field).

### `appAutosize` (on `<textarea>`)

| Input         | Type     | Default | Description |
|---------------|----------|---------|-------------|
| `appAutosize` | `number` | `8`     | Max rows before scrolling (bare `appAutosize` = 8; `0` = no limit). |

## Accessibility

- **Label** tied to the field by `for`/`id` (the field's own id is kept; without one, the frame creates it).
- **Description** (`aria-describedby`): the error or hint, the prefix/suffix text and the counter, in that order. `aria-invalid` with an error and `aria-required` with `required`.
- **Counter**: the visible "42/280" is `aria-hidden`; screen readers read the full sentence ("42 of 280 characters"). The limit warning uses an `aria-live="polite"` region, only for the last characters and after 1 s without typing.
- **Show password**: a real button, with a fixed name ("Show password") and the state in `aria-pressed`, pointing to the field (`aria-controls`). Focus stays on the button when toggling.
- **Visible focus**: the ring goes around the whole box (`:focus-within`), prefix/suffix included.
- **Growing textarea**: does not move focus or the caret; the manual resize handle is gone (the height is automatic).

## Tokens

The same as the Select, with defaults: `--sel-bg`, `--sel-fg`, `--sel-border`, `--sel-placeholder`, `--sel-focus-ring`, `--sel-disabled-bg`, `--sel-error`, plus `--accent` (border on focus) and `--muted` (hint, counter, prefix/suffix).
