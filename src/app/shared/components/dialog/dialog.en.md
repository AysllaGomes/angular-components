# Dialog

> Default texts in **English**, changeable in one place with [`provideUiLabels`](../../labels/labels.en.md) (`labels.*` in the tables below); each instance's input wins.

Accessible, lightweight modal for confirmations and small forms. Built with **Angular Standalone + HTML/Sass**, no UI frameworks.

- **File:** `src/app/shared/components/dialog/dialog.component.ts`  
- **Styles:** `src/app/shared/components/dialog/dialog.component.sass`  
- **Theme:** uses CSS custom properties and inherits the global `--accent`.

---

## Why it exists

A modal needs more than a box on top of the page: focus that moves in, stays trapped and returns to the button that opened it, `Esc` to close, an inert background for screen readers and a title tied to the dialog. Missing any of them leaves keyboard and screen reader users lost. This component does it on its own, with sizes and default actions.

## When to use

### Use when

- People must confirm an action before moving on (delete, discard changes).
- A small form that does not deserve its own page.
- The task has to be finished before going back to the rest of the screen.

### Prefer another

- A longer form or review, beside the content: use the [ActionBar](../actionbar/actionbar.en.md).
- Telling that something happened, without interrupting: use the [Toast](../toast/toast.en.md).
- A short explanation about an element: use the [Tooltip](../tooltip/tooltip.en.md).

## Usage

```html
<button appButton type="button" (click)="open = true">Delete order</button>

<app-dialog
  title="Delete order?"
  [(opened)]="open"
  describedBy="delete-desc"
  primaryLabel="Delete"
  secondaryLabel="Cancel"
  (primary)="delete()">
  <p id="delete-desc">This action cannot be undone.</p>
</app-dialog>
```

On close, focus returns to the "Delete order" button. For translated texts, pass your i18n strings to the inputs.

## API

### Inputs

| Prop              | Type                             | Default      | Description                                                    |
|-------------------|----------------------------------|--------------|----------------------------------------------------------------|
| `title`           | `string`                         | `'Dialog'`   | Header title.                                                  |
| `size`            | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'auto'` | `'md'` | Dialog width. `auto` measures the content on open (via `ResizeObserver`) and picks `sm`…`xl`. |
| `opened`          | `boolean`                        | `false`      | Controls visibility. Supports two‑way as `[(opened)]`.         |
| `closeOnBackdrop` | `boolean`                        | `true`       | Close when clicking the backdrop.                              |
| `describedBy`     | `string \| null`                 | `null`       | Id (or space-separated ids) of the text describing the dialog → `aria-describedby`. |
| `primaryLabel`    | `string \| null`                 | `null`       | Default primary button label. If `null`, it’s hidden.          |
| `secondaryLabel`  | `string \| null`                 | `null`       | Default secondary button label. If `null`, it’s hidden.        |

### Outputs

| Event            | Payload     | When                                   |
|------------------|-------------|----------------------------------------|
| `openedChange`   | `boolean`   | Mirrors `opened` changes (two‑way).    |
| `primary`        | `void`      | Click on the default primary button.   |
| `secondary`      | `void`      | Click on the default secondary button. |

### Slots / Projections

| Selector | Description |
|---|---|
| **default content** | Dialog body. |
| `[dialog-actions]` | Optional slot for **custom actions**. If present, default buttons are not rendered. |

## Accessibility

- `role="dialog"` and `aria-modal="true"` on the sheet.
- `aria-labelledby` points to the title element ID.
- `aria-describedby` (optional, via `describedBy`) points to the text describing the dialog, read together with the title when it opens.
- **Initial focus** goes to the close button. **Focus trap** keeps tabbing inside.
- **Focus restore**: on close (button, `Esc`, backdrop or `opened=false`), focus returns to the element that was focused before opening (usually the opener), if it is still in the page.
- **Inert background**: while open, the rest of the page gets `inert` (no focus, clicks or screen reader access). On close, only the elements the dialog marked are released (already-`inert` ones stay inert). To keep something active (such as notifications), add the `data-dialog-keep-active` attribute to it; `app-toast-container` already has it.
- **Keys:** `Esc` closes; `Tab`/`Shift+Tab` cycles focus.
- **Backdrop:** enabled by default; can be disabled with `closeOnBackdrop=false`.

## Examples

### 1) Basic (with i18n)

```html
<article class="card" style="display:grid;gap:.5rem;">
  <button class="pill" type="button" (click)="openDlg=true">
    {{ 'dialog.open' | t }}
  </button>
</article>

<app-dialog
  [title]="'dialog.title.delete' | t"
  size="auto"
  [(opened)]="openDlg"
  describedBy="dlg-delete-desc"
  [primaryLabel]="'dialog.primary.confirm' | t"
  [secondaryLabel]="'dialog.secondary.cancel' | t"
  (primary)="confirmDelete()">
  <p id="dlg-delete-desc">{{ 'dialog.body.delete' | t }}</p>
</app-dialog>
```

Suggested keys:
```ts
'dialog.open':             { pt: 'Abrir diálogo',   en: 'Open dialog' },
'dialog.title.delete':     { pt: 'Confirmar exclusão', en: 'Confirm delete' },
'dialog.body.delete':      { pt: 'Tem certeza? Esta ação não pode ser desfeita.', en: 'Are you sure? This action cannot be undone.' },
'dialog.primary.confirm':  { pt: 'Confirmar',       en: 'Confirm' },
'dialog.secondary.cancel': { pt: 'Cancelar',        en: 'Cancel' },
```

### 2) Custom actions

```html
<app-dialog
  [title]="'dialog.title.delete' | t"
  size="md"
  [(opened)]="openDlg">
  <p>{{ 'dialog.body.delete' | t }}</p>

  <div dialog-actions>
    <button class="btn--ghost btn" type="button" (click)="openDlg=false">
      {{ 'dialog.secondary.cancel' | t }}
    </button>
    <button class="btn" type="button" (click)="confirmDelete()">
      {{ 'dialog.primary.confirm' | t }}
    </button>
  </div>
</app-dialog>
```

## Tips

- Keep titles and labels short and clear.
- For forms, shift the initial focus to the first field after opening.
- Avoid overly tall content; the body supports vertical scrolling.
- On mobile (≤ 480px) the dialog stretches to full width.

---

## Troubleshooting

- **“ResizeObserver is not defined”** under SSR: guard the access with a `window`/`ResizeObserver` check. The component already guards, but ensure it only runs in the browser.
- **Focus not trapped:** verify no inner element has `tabindex="-1"` unexpectedly or an `autofocus` stealing focus.
