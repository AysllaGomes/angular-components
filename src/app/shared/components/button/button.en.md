# Button (appButton)

Reusable directive to style `<button>`/`<a>` with theme tokens.

**Inputs**
- `variant`: `"solid" | "outline" | "ghost" | "link"` (default `"solid"`)
- `tone`: `"accent" | "neutral" | "danger"` (default `"accent"`)
- `size`: `"xs" | "sm" | "md" | "lg" (default `"md"`)

**Examples**
```html
<button appButton="ghost">Save</button>
<button appButton="ghost" tone="neutral">Back</button>
<button appButton="ghost" size="sm">‹</button>
<a appButton variant="link" href="#">Learn more</a>
```

**A11y**
- Maintains native `<button>/<a>` semantics.
- `:focus-visible` states with theme/accent-consistent ring.

## What to copy

To use the Button in another Angular project, copy into a `shared/` folder **keeping the same folder structure** (imports are relative). Specs (`*.spec.ts`) and docs are optional.

| What | Copy |
|---|---|
| The component | `components/button/` |
| Types | `model/type/button/bnt-size.type.ts`<br>`model/type/button/bnt-tone.type.ts`<br>`model/type/button/bnt-variant.type.ts` |

Global styles: add to your project's `styles.sass` (or `styles.scss`):

```sass
@use '<your-folder>/shared/components/button/button' as *
```

Depends only on `@angular/core`. In total: 5 files, ~269 lines. CSS variables have defaults: the look works without this project's theme, which can still override them.
