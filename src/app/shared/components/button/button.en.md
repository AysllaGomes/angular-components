# Button (appButton)

Directive that gives a native `<button>` or `<a>` the theme look: variant, tone and size, with busy and disabled states.

- **File:** `src/app/shared/components/button/button.directive.ts` (global style in `button.sass`)

## Why it exists

A button component that wraps `<button>` often hides native attributes (`type`, `disabled`, `aria-*`) and gets in the way of forms and links. As a directive, `appButton` only applies the look (variant, tone and size with the theme tokens) and lets the native element do the rest: keyboard, focus, form submission and navigation.

## When to use

### Use when

- Any action on the screen: use it on a `<button>`.
- A link that has to look like a button: use it on an `<a href>`, which is still a link.
- Destructive actions: use `tone="danger"`.

### Prefer another

- An icon-only button: use the button and name it with the [Tooltip](../tooltip/tooltip.en.md) (`tooltipAsLabel`).
- Going to another page inside a sentence: use a plain link, without `appButton`.

## What to copy

To use the Button in another Angular project, copy into a `shared/` folder **keeping the same folder structure** (imports are relative). Specs (`*.spec.ts`) and docs are optional.

| What | Copy |
|---|---|
| The component | `components/button/` |
| Types | `model/type/button/bnt-size.type.ts`<br>`model/type/button/bnt-tone.type.ts`<br>`model/type/button/bnt-variant.type.ts` |

Global styles: add to your project's `styles.sass` (or `styles.scss`):

```sass
@use '<your-folder>/shared/components/button/button' as *
```

Depends only on `@angular/core`. In total: 5 files, ~269 lines. CSS variables have defaults: the look works without this project's theme, which can still override them.

## Usage

```html
<button appButton type="submit">Save</button>
<button appButton="ghost" tone="neutral" type="button">Back</button>
<button appButton="outline" tone="danger" type="button">Delete</button>
<button appButton [busy]="saving()" type="submit">Send</button>
<a appButton variant="link" href="/help">Learn more</a>
```

The variant can go in the attribute itself (`appButton="ghost"`) or in `variant`, which wins. The empty attribute (`<button appButton>`) is `solid`.

## API

### Inputs

| Property | Type | Default | Description |
|---|---|---|---|
| `appButton` / `variant` | `'solid' \| 'outline' \| 'ghost' \| 'pill' \| 'link'` | `'solid'` | Button shape. `variant` wins over `appButton`. |
| `tone` | `'accent' \| 'neutral' \| 'danger'` | `'accent'` | Palette: theme accent, neutral or destructive action. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'md'` | Size. |
| `block` | `boolean` | `false` | Takes the full width. Accepts the empty attribute. |
| `iconOnly` | `boolean` | `false` | Square for a single icon. Needs a name (`aria-label` or a Tooltip with `tooltipAsLabel`). |
| `busy` | `boolean` | `false` | Loading: shows a spinner, sets `aria-busy` and blocks clicks. |
| `disabled` | `boolean` | `false` | Disables. On `<button>` it uses the native `disabled`; on `<a>`, `aria-disabled` and it leaves the Tab order. |

## Accessibility

- It is still the native `<button>` or `<a>`: Enter and Space, form submission and navigation work with nothing extra.
- `busy` and `disabled` block clicks. On `<button>` they become the `disabled` attribute; on `<a>`, which has no `disabled`, they become `aria-disabled="true"` and `tabindex="-1"`.
- `busy` sets `aria-busy="true"`; the button text stays there for screen readers.
- Focus ring (`:focus-visible`) in the theme accent color, on keyboard focus only.
- An icon-only button (`iconOnly`) has no visible text: name it with `aria-label` or with the [Tooltip](../tooltip/tooltip.en.md) (`tooltipAsLabel`).
